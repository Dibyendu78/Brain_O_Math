About the Olympiad

Structured competition for school learners

Organized by {{ event_config.organizer_name }}, the Brain-O-Math Olympiad {{ event_config.event_year }} is an interschool assessment for students from Classes III to XII. It supports critical thinking, reasoning, and confidence-building through a fair and well-managed competitive process.

The program is designed to create a positive experience for students, coordinators, and schools. It follows transparent procedures for question design, evaluation, and result publication.

Focused learning

Assessment resources and a four-subject structure motivate strong analytical skills across Classes III to XII.

Fair evaluation

Clear marking guidelines and prompt result updates support credibility for students and teachers.

School collaboration

Coordinators manage student registration and communication directly, making participation smooth for schools.

Categories and subjects

  • Category A: Classes III–IV
  • Category B: Classes V–VI
  • Category C: Classes VII–VIII
  • Category D: Classes IX–X
  • Category E: Classes XI–XII
  • All categories cover English, Mathematics, Science, and Computer Science

Question paper blueprint

  • English: 50 questions, 60 marks
  • Computer Science: 50 questions, 60 marks
  • Science: 50 questions, 60 marks
  • Mathematics: 50 questions, 60 marks
  • Each paper includes an Achievers Section (HOTS)
